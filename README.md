## Project Overview

This project demonstrates a complete manual QA testing process performed on the IMDb website.

The project included exploratory testing, test planning, functional decomposition, test case design and implementation, manual test execution, non-functional testing, risk analysis, and final test reporting.

A total of **92 test cases** were designed and executed across multiple functional and non-functional areas.

All planned test cases were executed successfully.

> No defects were identified within the tested scope and test environment.

---

## Test Environment

- **Platform:** Web
- **Device:** MacBook
- **Operating System:** macOS
- **Browser:** Safari
- **Network:** Wi-Fi
- **Environment:** IMDb Production Website
- **Testing Type:** Manual Testing

Testing was performed on the live IMDb production website, meaning that content and dynamic data could change during the testing period.

Compatibility testing was performed using Safari and different viewport sizes. Testing on a real mobile device or additional browsers was outside the defined project scope.

## Test Process

### 1. Exploratory Testing

Initial exploratory testing was performed to understand the system, identify important user flows, and support the creation of the formal test documentation.

### 2. STP – Software Test Plan

The STP defines:

- Test objectives
- Testing scope
- Test environment
- Entry and exit criteria
- Schedule
- Deliverables
- Risks and mitigation plans

### 3. STD – Software Test Description

The system was divided into functional and non-functional testing areas to create an organized testing structure and define the required coverage.

### 4. Test Cases

Detailed test cases were created based on the STD.

Each test case includes:

- Test case identification
- Preconditions
- Test steps
- Expected results

A total of **92 test cases** were implemented and executed.

### 5. STR – Software Test Results

The STR summarizes the testing process, execution results, risk status, quality evaluation, limitations, conclusions, and recommendations for future testing.

## Key Project Limitations

The project was performed within a predefined test scope.

The main limitation was browser compatibility coverage. Testing was performed using **Safari only**, and no testing was performed using a real mobile browser on a physical mobile device.

Therefore, the test results should not be interpreted as proof of full compatibility across all browsers, operating systems, devices, or possible user scenarios.
